## Claiming workflow (same for most Tier 1/2 platforms)

1. Search the platform first for an existing unclaimed listing (many businesses get auto-listed
   from data aggregators) — claiming an existing one preserves any reviews already attached to it.
   Creating a duplicate instead fragments reviews and NAP signals, which is worse than doing
   nothing.
2. Verify ownership — usually a phone call/OTP to the primary number, sometimes an email link or
   a physical postcard (rare for these platforms, common for Google only).
3. Fill every field using the Step 0 master record verbatim — no shorthand, no "same as Google"
   placeholders.
4. Add the same primary category decided in Day 1, and 2-3 photos (reuse Day 4's photo shot-list
   output once real photos exist) so listings aren't left with a blank placeholder image, which
   itself hurts trust.
5. Log the listing in the tracking table below immediately after claiming — don't batch this at
   the end, it's easy to forget one.
